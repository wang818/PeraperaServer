## BUG FIX: `_fetch_video_info` raised NameError (httpx undefined)
- Symptom: `GET /api/v1/common/yt_info` always returned 502 `获取视频元信息失败`. My earlier direct debug masked it because my throwaway script imported `httpx` at top level.
- Root cause: `common.py` only imported `httpx` locally inside `download_youtube_audio` and `_fetch_audio` (function-scoped), never at module level. `_fetch_video_info` used `httpx.AsyncClient(...)` at module scope → `NameError: name 'httpx' is not defined`. In `yt_audio` this was silently swallowed (metadata came back null); `yt_info` has no fallback so it 502'd.
- Fix: added `import httpx` at module top (line ~20) and removed the two redundant function-local `import httpx` lines. Also made `_fetch_video_info` accept `return_error=True` to surface the real API error/status to callers (so future failures are diagnosable instead of a generic 502).
- Verified: simulation of full path now returns ok=True for watch/youtu.be/shorts URL forms; module imports cleanly; `/yt_info` still requires `get_current_user`.

## BUG FIX: `yt_audio` 400 "Could not retrieve the video duration"
- Symptom: `GET /api/v1/common/yt_audio` returned 400 `video_duration_unavailable` ("Could not retrieve the video duration, please try again later"). Source: `quota_service.get_video_duration_seconds` returned None → yt-dlp failed to extract duration from YouTube.
- Root cause: duration was sourced ONLY from yt-dlp, which is flaky/blocked vs YouTube. RapidAPI `youtube-v2/video/details` already returns duration as `video_length` (seconds) reliably.
- Fix in `common.py` `download_youtube_audio`: (1) fetch video_info (RapidAPI) first; (2) parse duration via new `_parse_duration(video_info)` helper (handles string/number + bad input → None); (3) fall back to `quota_service.get_video_duration_seconds` (yt-dlp) only if RapidAPI duration missing; (4) 400 only if BOTH fail. `info_title` now computed after video_info available.
- Added `_parse_duration(video_info)` helper. Verified: RapidAPI video_length=7456 parsed correctly, yt-dlp skipped; None / "abc" inputs → None (fallback path). Module imports OK.

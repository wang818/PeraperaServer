# 2026-07-28

## Project familiarization — PeraperaServer

FastAPI backend for the PeraPera language-learning companion app (iOS client).

### Non-obvious facts (vs README)
- `README.md` is OUTDATED — describes a generic user/password scaffold. `CLAUDE.md` is the authoritative doc.
- Most complex subsystem = Apple IAP module (`app/api/v1/endpoints/iap.py` + `app/services/entitlement_service.py`, `apple_api_client.py`, `apple_jws_verifier.py`, `apple_jwt_service.py`). Handles StoreKit2 tx verification, legacy receipt verify, App Store Server Notification V2 webhook, subscription refresh, restore.
- Auth is **captcha-based email login with auto-registration** (no passwords). `POST /api/v1/auth/login` {email, captcha}; `GET /auth/sendCaptcha` has tiered rate limits.
- Tables auto-created on startup via `Base.metadata.create_all` in `main.py` lifespan (Alembic present but base tables auto-created).
- i18n is in-code dict in `app/core/i18n.py` (18 langs), language from `Accept-Language` header.

### Data model
- `users`, `captcha_records`, `user_settings` (keyed by user_uuid), IAP: `iap_products`, `iap_transactions` (immutable audit log), `user_entitlements` (one row per user_id+product_id, Postgres ON CONFLICT upsert).

### Run
- Dev: `python3 run.py` (or uvicorn). Prod: Nginx→Uvicorn→FastAPI→PostgreSQL, systemd `perapera.service`.
- Env: `.env` (DATABASE_URL, SECRET_KEY, RAPIDAPI_KEY, COS_*, SMTP_*, APPLE_IAP_*).
